# Projectopdracht

Doorheen dit semester bouw je je **eigen responsieve webshop**. Je verzint zelf wat je verkoopt.

Je hoeft dat niet in één keer te kunnen. Het project bestaat uit **7 deelopdrachten** die aansluiten bij wat je op dat moment in de labo's leert. Wat je in de les leert, pas je meteen toe op je eigen shop.

## Waar begin je?

1. Lees de [**Projectinformatie**](info.md): wat je bouwt, hoe je je repository aanmaakt, de [planning](info.md#planning-and-indienen) en de regels.
2. Bekijk de [**Evaluatie**](evaluatie.md), zodat je van bij de start weet waarop je beoordeeld wordt.
3. Start met [**deelopdracht 1**](deelopdracht-1-concept-content.md).
